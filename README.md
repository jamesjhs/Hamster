# Hamster
Tools around a hamster logger

The **PythonServer** directory contains the current active Flask web server.  It combines a background ESP32 data logger with a website that includes a live monitor, analytics charts, a text-based blog, a photo gallery, and a minimal Kindle-compatible page.  See [USER_MANUAL.md](USER_MANUAL.md) for full documentation.

The old Node.js implementation has been retained in `node-deprecated/` for reference only.
